# Device Tree for Nintendo Switch

## Spec Sheet

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Quad-core ARM Cortex-A57 @ 1.02 GHz + Quad-core Cortex-A53
Chipset | NVIDIA Tegra X1 (20 nm)
GPU     | NVIDIA GM20B (Maxwell-based)
Storage/Memory  | 32GB eMMC, 4GB LPDDR4 RAM
Shipped Android Version | Horizon OS (Nintendo custom OS); Android unofficially ported
MicroSD | microSDXC (up to 2TB, UHS-I supported)
Battery | Li-Ion 4310 mAh, non-removable
Display | 6.2 inches, 97.6 cm² (~70% screen-to-body ratio), 1280 x 720 pixels
Camera  | None (IR motion camera on right Joy-Con only)
